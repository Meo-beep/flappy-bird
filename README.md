# flappy-bird
Xin giới thiệu với mọi người game Flappy Bird do mình tự làm và phát triển! 🥳  ✨ Có gì trong game? - 🐤 Nhiều loại chim để lựa chọn và mở khóa. - 🗺️ Nhiều bản đồ với phong cách khác nhau. - 🎁 Vật phẩm hỗ trợ trong lúc chơi. - 🏆 Bảng xếp hạng trực tuyến. - 🎮 Cố gắng vượt qua các chướng ngại vật và lập kỷ lục của riêng mình!
